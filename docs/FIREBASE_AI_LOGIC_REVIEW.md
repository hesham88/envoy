## What's beyond the docs

- The device guard (availability check, network tripwire, `inferenceSource` assertion, session cleanup), one queue for all model calls, and cancellable on-device steps.
- The outbound guard: every approved excerpt is re-checked for raw or disguised values (red team 28/28).
- Encrypted local history (AES-GCM, non-extractable key, optional passcode).

## Watching judging traffic (10–16 Dec)

None of these pages store prompt or reply text:

- **Requests, errors and latency through Firebase AI Logic:** [Firebase AI Logic API metrics](https://console.cloud.google.com/apis/api/firebasevertexai.googleapis.com/metrics?project=envoy-hybrid-ai). Filter by method and response code: 429 means a quota was hit, 401 means App Check refused a request.
- **Quota per model and per day:** [Gemini API quotas](https://console.cloud.google.com/apis/api/generativelanguage.googleapis.com/quotas?project=envoy-hybrid-ai). Hydrogen's free tier is 20 requests a day, and failed requests count. Flash-Lite is the default, so judges rarely reach Hydrogen; when Hydrogen refuses, Envoy answers with Flash-Lite and says so.
- **Verified vs refused requests:** [Firebase console > App Check > APIs](https://console.firebase.google.com/project/envoy-hybrid-ai/appcheck/apis). A rise in unverified requests means reCAPTCHA is scoring visitors below 0.3.
- Quotas reset at midnight Pacific (10:00 Cairo).
